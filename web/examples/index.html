Step two is a single deploy command. Step three is where most teams sink time — keeping things running. Schedules are defined in code with cron syntax; the homepage example runs weekdays at 9am.

This is the differentiator: not a sandboxed function call but a full Linux machine per session — shell, read-write filesystem, apt/npm/pip, full network egress. Sessions are durable: they stream, can be steered mid-run, hibernate when idle and resume. On security, model keys are not in the runtime, and connection secrets are bound to a single origin and injected after requests leave the machine — so the agent can open a GitHub PR but cannot read or exfiltrate the token. That's a strong answer for enterprise buyers asking about agent security.

For an early-stage budget this matters: there's no monthly commitment on pay-as-you-go, and you start with $10 of free credit. Tokens pass through at API rates with no markup — and if you bring your own key or a Codex subscription, the token meter reads zero. Machines default to 2 GB / 1 vCPU at $0.00315 per minute and burst automatically to 4 GB or 8 GB when needed. The site's own example: a session running ten minutes a day costs about $1 a month. Plans are simply prepaid credit with a 10× multiplier; when it runs out you continue on PAYG rates. Verify current pricing on the site before quoting it to investors or customers.
